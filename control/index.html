Catálogo dinámico · una sola fuente

La idea es que BUSCO Control termine siendo el lugar donde se actualiza cada herramienta una sola vez. Desde aquí puedes importar el catálogo completo y exportar un JSON limpio para que la web pública lea esos datos sin mantener 46 fichas actuales a mano.
1 · CatálogoNombre, descripción, categoría, web oficial y estado público.
2 · AfiliaciónEnlace, comisión, cookie, atribución y condiciones, solo para uso interno.
3 · RendimientoClics y conversiones se cruzan para saber qué herramientas funcionan de verdad.
